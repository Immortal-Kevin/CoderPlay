## 构建与实机记录

- Release 构建通过。核心自动化测试 11/11 通过。包含离线补算中途注入错误时完整回滚，重开后补算一次。
- `Tests.Desktop` 在真实 Windows 交互会话通过 7 项检查。Raw Input 注册与注销、原生物理像素位置、置顶、不夺焦点、鹅身体命中、透明角穿透与全穿透窗口均通过。主屏 DPI 240。
- 自包含便携包与 MSI 生成。Windows Installer 在独立测试路径安装成功，主程序字节与便携版一致，开始菜单快捷方式存在。卸载成功，应用和快捷方式移除，同一用户实际使用的 SQLite 存档保留。
- 托盘退出、受保护程序、手持长按、真实连续按键计数、全屏游戏和长时性能需要进一步实测。
