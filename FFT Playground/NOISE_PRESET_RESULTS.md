# v1.0.2 — 可调正常运行底噪

新增“正常运行（有底噪）”：正常转频和谐波保持不变，默认高斯白噪声σ=0.15 a.u.。
在“采样 / 分析”页编辑“背景底噪 σ (a.u.)”后按“生成 / 更新”；0关闭。
原“正常运行”预设保持σ=0.025，不改变原有场景行为。固定种子便于对比。
这是时域标准差，频谱底线同时受Fs/N/窗函数影响；不是固定dB噪声地板。
真实监测还可能存在有色、非平稳背景，本预设仅模拟宽带随机噪声。

实际执行 pytest：68通过、0失败。新GUI集成检查验证预设选择后σ同步为0.15，
编辑为0并更新后关闭底噪；200–500 Hz频带的噪声能量相应下降，正常谐波保持不变。
其他数值/Envelope/CSV/PNG/启动/DPI回归测试一并通过。

无新增依赖、无许可证变化。便携包继续使用已审计的同一运行时和自有启动器，
构建后对实际ZIP重新执行文件、原生依赖、标准库及许可证审计。
