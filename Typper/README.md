# Typper

蓝白配色的本地随机键入草稿页，无依赖、无构建、无网络请求。双击 `index.html` 即可使用。

- 最小布局 1280 × 640，可随窗口扩大；浏览器 F11 可全屏。
- 切换中文 / English 界面，随机输入 `a-z`、`A-Z`、`0-9`。
- 滑块设置间隔，或输入精确的最小 / 最大秒数，每次在范围内均匀随机取值。
- 最快每秒 30 次（1/30 秒），最慢每 300 秒一次。将两端设为相同数值可固定间隔。
- 点击开始后倒数三秒；倒数和运行时按任意键或点击停止均可取消。停止按键不会写进草稿。
- 随机字符在草稿光标位置插入；草稿可以自由编辑，无主动长度限制（受浏览器资源限制）。
- 草稿自动保存在当前浏览器的 localStorage；存储不可用或超出配额时显示提示。清屏同时清除保存的草稿。
- 浏览器后台标签页可能节流计时器，系统休眠期间不会持续键入。本页仅编辑自己的草稿，不向其他应用发送按键。

## Windows 系统键入入口（2026-11-03）

双击 `Typper.pyw`，或运行 `python typper_native.py`（Python 3.10+，自带 Tkinter，无 pip 依赖）。原 `index.html`、网页 UI 和浏览器 localStorage 草稿保持原样；网页仍只编辑自己的内容，不生成系统按键。

新增原生入口发送 Windows SendInput 虚拟键，随机 a–z、0–9，按住 150 ms、至少释放 150 ms。随机间隔支持 1/30–300 秒，兼容模式实际将低于 300 ms 的间隔提升至 300 ms，最高约 3.33 次/秒。

默认输入原生窗口内的临时草稿，三秒后开始；草稿失去焦点自动停止。此草稿控件禁用 IME，避免中文组词影响随机 ASCII 字符。原生草稿不与网页草稿同步，也不自动保存。Caps Lock、键盘布局仍会影响实际字符。

勾选“向倒计时后有焦点的其他应用键入”后，请在三秒内点击目标应用的文本编辑区。外部目标的输入法由该应用管理。F12 可全局紧急停止；点击停止或关闭窗口也释放本程序按下的键。按住修饰键时会停止，避免组合快捷键。原生入口没有采用网页“任意键停止”，避免其自身注入按键触发停止。

普通权限下使用；管理员窗口可能因 UIPI 拒绝输入。BongoCat 计数受其轮询、系统调度及应用设置影响，不保证任意负载下逐次计数。
