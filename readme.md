## 中文

我是 **Vibe Coder 9527**，这是我的练习小乐园，欢迎您的来访。

CoderPlay 收集可在本地运行的小工具，目标是在没有网络时也能完成日常任务，智能功能无需调用云端 API。项目源于闲暇时的编程消遣与实践，也会尝试复现从其他地方发现的有趣工具。

| 应用 | 用途 |
| --- | --- |
| AIsharpner | 本地照片锐化、细节增强与分辨率调整。 |
| CarCoating DIY | 车膜设计素材处理、三维建模、渲染与成品检查脚本。 |
| [Desktop Cleaner](Desktop%20Cleaner/) | 桌面图标网格整理与布局恢复，适用于 Windows 11；目前通过主屏实测，副屏支持仍待完善。 |
| [FFT Playground](FFT%20Playground/) | 离线振动信号模拟、FFT 频谱与包络分析教学工具，支持中英文界面。 |
| Chinglish Simulator | 基于本地语言模型的中译英工具，可调节中式英语风格与语气。 |
| Simple Generator | 本地图片生成、风格转换与提示词中译英。 |
| Tapper | 可配置间隔的 Windows 鼠标连点器。 |
| TypingTrainer | 离线打字训练、文本导入、成绩统计与历史记录。 |
| Typper | 随机字符键入工具，提供浏览器草稿页与 Windows 原生入口。 |
| name changer | 按编号规则批量重命名或复制文件。 |

未来将逐步引入轻量本地模型辅助日常功能，并保留无需模型的基础能力，让无法联网下载模型时也有工具可用。已有模型与依赖准备完成后，智能功能可在本地离线运行。核显加速目前以 Intel 核显为支持与验证重点，后续尝试兼容 AMD 核显。各应用的环境要求与设备支持详见其目录说明。

## English

I’m **Vibe Coder 9527**. This is my little playground for coding practice. Welcome!

CoderPlay brings together small local utilities for everyday tasks, including use without an internet connection. Its AI features aim to run without cloud APIs. The project began as a way to spend free time experimenting with code, and also includes personal takes on interesting tools found elsewhere.

| Application | Purpose |
| --- | --- |
| AIsharpner | Local photo sharpening, detail enhancement and resizing. |
| CarCoating DIY | Scripts for vehicle-wrap assets, 3D modeling, rendering and output checks. |
| [Desktop Cleaner](Desktop%20Cleaner/) | Desktop icon grid arrangement and layout restoration for Windows 11; tested on the primary display, with secondary-display support still being refined. |
| [FFT Playground](FFT%20Playground/) | Offline vibration signal simulation, FFT spectra and envelope analysis for learning, with Chinese and English interfaces. |
| Chinglish Simulator | Local-model Chinese-to-English translation with adjustable Chinglish style and tone. |
| Simple Generator | Local image generation, style conversion and Chinese-to-English prompt translation. |
| Tapper | A Windows mouse auto-clicker with configurable intervals. |
| TypingTrainer | Offline typing practice, text import, performance statistics and history. |
| Typper | Random character typing with a browser scratchpad and a native Windows interface. |
| name changer | Batch file renaming or copying using numbering rules. |

Future work will introduce lightweight local models while retaining basic features that work without a model, so useful tools remain available when models cannot be downloaded. AI features run offline once their models and dependencies are installed. Integrated-GPU support and validation currently focus on Intel, with AMD compatibility planned for exploration. See each application’s documentation for its requirements and supported devices.

## Русский

Я **Vibe Coder 9527**. Это моя небольшая площадка для практики программирования. Добро пожаловать!

CoderPlay объединяет локальные утилиты для повседневных задач, в том числе без подключения к интернету. Цель функций ИИ — работа без облачных API. Проект появился как увлечение для свободного времени и обучения. Здесь также появляются мои реализации интересных инструментов, найденных в других источниках.

| Приложение | Назначение |
| --- | --- |
| AIsharpner | Локальное повышение резкости и детализации фотографий, изменение размера. |
| CarCoating DIY | Скрипты подготовки материалов для автомобильных плёнок, 3D-моделирования, рендеринга и проверки результатов. |
| [Desktop Cleaner](Desktop%20Cleaner/) | Упорядочивание значков рабочего стола Windows 11 по сетке и восстановление расположения. Проверено на основном экране; поддержка дополнительного экрана дорабатывается. |
| [FFT Playground](FFT%20Playground/) | Офлайн-инструмент для изучения моделирования вибрационных сигналов, спектров FFT и анализа огибающей, с китайским и английским интерфейсами. |
| Chinglish Simulator | Перевод с китайского на английский с помощью локальной языковой модели, с настройкой стиля Chinglish и тона. |
| Simple Generator | Локальная генерация изображений, преобразование стиля и перевод запросов с китайского на английский. |
| Tapper | Автокликер мыши для Windows с настраиваемыми интервалами. |
| TypingTrainer | Офлайн-тренировка печати, импорт текстов, статистика результатов и история. |
| Typper | Ввод случайных символов в браузерном черновике или через отдельный интерфейс Windows. |
| name changer | Пакетное переименование или копирование файлов по правилам нумерации. |

В планах — подключать небольшие локальные модели для вспомогательных функций и сохранять базовые возможности, работающие без моделей. Это позволит пользоваться инструментами, даже когда скачать модель невозможно. Функции ИИ работают офлайн после установки моделей и зависимостей. Поддержка и проверка встроенной графики сейчас сосредоточены на Intel; в дальнейшем планируется изучить совместимость с AMD. Требования и поддерживаемые устройства указаны в документации каждого приложения.

## Español

Soy **Vibe Coder 9527**. Este es mi pequeño espacio para practicar y disfrutar de la programación. ¡Bienvenido!

CoderPlay reúne pequeñas herramientas locales para tareas cotidianas, incluso sin conexión a internet. Sus funciones de IA buscan ejecutarse sin API en la nube. El proyecto nació como una afición para aprender y pasar el tiempo, y también incorpora versiones propias de herramientas interesantes encontradas en otros lugares.

| Aplicación | Propósito |
| --- | --- |
| AIsharpner | Mejora local de nitidez y detalle fotográfico, y cambio de tamaño. |
| CarCoating DIY | Scripts para preparar diseños de vinilos para vehículos, modelar en 3D, renderizar y revisar resultados. |
| [Desktop Cleaner](Desktop%20Cleaner/) | Organización en cuadrícula y restauración de iconos del escritorio de Windows 11. Probado en la pantalla principal; la compatibilidad con pantallas secundarias sigue en desarrollo. |
| [FFT Playground](FFT%20Playground/) | Herramienta educativa sin conexión para simular señales de vibración y analizar espectros FFT y envolventes, con interfaz en chino e inglés. |
| Chinglish Simulator | Traducción del chino al inglés mediante un modelo local, con estilo Chinglish y tono ajustables. |
| Simple Generator | Generación local de imágenes, conversión de estilo y traducción de instrucciones del chino al inglés. |
| Tapper | Clics automáticos del ratón en Windows con intervalos configurables. |
| TypingTrainer | Práctica de mecanografía sin conexión, importación de textos, estadísticas e historial. |
| Typper | Escritura de caracteres aleatorios con un borrador en el navegador y una interfaz nativa de Windows. |
| name changer | Cambio de nombre o copia de archivos por lotes mediante reglas de numeración. |

La evolución prevista incorpora modelos locales ligeros como apoyo y conserva funciones básicas que puedan usarse sin modelos, para disponer de herramientas cuando no sea posible descargarlos. Las funciones de IA trabajan sin conexión una vez instalados sus modelos y dependencias. La compatibilidad y las pruebas con gráficos integrados se centran actualmente en Intel; más adelante se explorará AMD. Los requisitos y dispositivos compatibles se detallan en la documentación de cada aplicación.
